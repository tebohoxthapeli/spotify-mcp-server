# Implemented Features

## Phase 1

1. Get currently playing track info
2. Get playback state (playing, paused, stopped)
3. Get current playback position in seconds
4. Get volume level (0–100)
5. Get shuffle state
6. Get repeat mode
7. Resume playback
8. Pause playback
9. Toggle play/pause
10. Skip to next track
11. Skip to previous track
12. Play a specific track by URI
13. Seek to a position in seconds
14. Set volume (0–100)
15. Enable/disable shuffle
16. Set repeat mode
17. List the user's playlists
18. Get tracks from a specific playlist
19. Create a new playlist
20. Delete (unfollow) a playlist
21. Add tracks to a playlist
22. Remove tracks from a playlist
23. Update playlist metadata
24. Reorder tracks within a playlist

## Phase 2

25. Search for tracks, artists, albums, or playlists
26. Get recently played tracks
27. Add a track or episode to the queue
28. Get track recommendations from seed artists or tracks
